# Support — turfbuild

This is the org-wide support guide for all [`turfbuild`](https://github.com/turfbuild)
repositories. A repository may override it with its own `SUPPORT.md`.

| Need | Where |
| --- | --- |
| Questions, ideas, show and tell, chat | Discord: https://turf.build/discord/ |
| Bugs and feature requests in Turf | https://github.com/turfbuild/turf/issues |
| Bugs in an example, the formula or a provider | That repository's Issues |
| Release notes by email | https://turf.build/newsletter/ |
| Follow along | [LinkedIn](https://www.linkedin.com/company/turfbuild/) · [X](https://x.com/turfbuild) |
| Companies evaluating Turf | https://turf.build/licensing/#pilot |
| Anything else | contact@turf.build |
| A security vulnerability, privately | security@turf.build — see [SECURITY.md](SECURITY.md); never a public issue |

Everything else about reaching us is at https://turf.build/community/.
